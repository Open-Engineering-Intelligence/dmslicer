# 05C 固定工程容差与有限尺度实验

## 范围与构造

本轮仅运行 A01 平面与修复后的 A07 同轴轴孔，在 `s={0.01,1,100}`、`q=δ/τE∈{-4,-2,-1.1,-1,-0.9,-0.5,-0.1,0,0.1,0.5,0.9,1,1.1,2,4}` 下的有限矩阵。工程容差固定为 `τE=0.1 mm`，因此 `δ=0.1q mm`，不随尺度缩放。A01 的所有正尺寸盒体均可构造；A07 仅在 `0 < r_s+δ < R_s` 时构造，并逐项保留域外记录，不生成伪造 STEP。

## 当前真值与验收

A01 的共同厚度为 `max(0, min(h_s,2h_s+δ)-max(0,h_s+δ))`，共同体积为 `a_s b_s t`，交集维数由该区间关系确定。有效 A07 中，`δ<0` 的共同体积为 `π(r_s²-(r_s+δ)²)l_s`，`δ=0` 的共同面积为 `2πr_sl_s`，`δ>0` 无当前交集。实际测量只从同一 tracked STEP 与 FreeCAD B-rep 输出写入；随后才用独立真值验证。主结果是有效构造域中的 current tuple 与 native-absolute 测量验收；归一化结果是辅助项，按当前尺度真值和 `δ/s` 参考计算。

## 执行

`$env:PYTHONPATH='src'; py -m dmslicer.contact_fixed_tolerance_pilot_05c generate` 建立 90 项计划、域检查和有效输入；`run` 对有效 STEP 分两轮独立测量；`revalidate` 仅复核已保存的实际证据。定向 pytest 覆盖域、真值、固定容差、独立验收和统计；最终运行相关完整回归。停止范围不含旋转、NURBS、多体、gradient、field、slicing 或自动修复。
