# 06B 平面部分覆盖界面校正与分区融合

06B 在 06A 的授权、有限数值和纯法向平移约束之上，增加了部分覆盖平面界面的实际 B-rep 分区。输入由独立生成的 STEP 再导入分析；`expected.json` 只在操作完成后参与验收，不能决定实测动作。

P07 验证双方 60% 覆盖（480 mm²）和各 320 mm² 剩余面；P08 验证 Side_2 全覆盖、其 Remaining 为真实 `EMPTY`；P09 在可丢弃的候选副本上得到零面积 `face.common`，因此拒绝且不执行平移或融合。

成功路径重新选择实际承载面并以 `face.common` / `face.cut` 保存 Common 与双方 Remaining。验收同时核对有限数值、正间隙、策略授权、位移预算、单位法向与平移向量、切向不变性、面积/空间守恒、融合和 STEP 重导入残余。篡改策略、动作、NaN/无穷值、覆盖率或分区都会生成结构化 FAIL；失败验收不会覆盖既有成功输出。

本实现未修改 06A 的 FreeCAD 平移、common/fuse 算法、历史 fixture/policy/expected 或既有阈值；06B 使用自身 P07–P09 fixture 和已有数值规则。
