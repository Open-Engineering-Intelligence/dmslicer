当前使用一个入口：`http://127.0.0.1:56810/`。运行根目录 `start_geometry_viewer.ps1` 会打开浏览器；已有工作台会被复用，新启动服务在后台运行，关闭浏览器不会删除数据或停止服务。`-NoBrowser` 可只启动/检测服务。端口被其他程序占用时脚本报错，不擅自停止该程序。

## 三种视图

- **整体查看**：在同一坐标空间叠加对象；显示状态不构成几何关系。
- **操作对照**：按包内展示分组分栏，同步旋转缩放。隐藏对象仍明确标记“已隐藏”，不被误读为未产生。界面关联与实际补丁分组分开。
- **证据查看**：阅读包内文件清单、来源/诊断、已有计算事实与验证记录。没有缓存的包也能读取结果，不启动 CAD。

三种视图共享同一包与选择/显隐状态。单案例包不再显示重复案例选择器，空操作组不显示无用按钮；CASE01 明确未产生的融合结果仍显示其状态。

主入口始终是手动选择一个 `.dmslicer` 文件；可选示例列表只是便利入口，复用同一读取器。示例 registry 位于 `evidence/GEOMETRY-WORKBENCH-01/unified-001/samples.json`，仅将明确列出的包暴露给页面，不暴露任意文件路径。包含 CASE01、C02、U05、S04 和 P-MULTI；每个副本均核验源文件字节完整性，来源目录没有移动或改写。

## 范围与验收

Scope：统一本机入口及三种只读结果视图；移植有效显示能力；安全退役重复查看服务。

Acceptance：五类已有真实包可在同一页面导入，操作分栏完整，切换视图不丢失显隐和选择；示例入口复用包读取器；闲置连接不阻塞；重复启动不新增服务；旧三端口停止且原历史文件仍存在。

Stop conditions：不重算接触/Boolean，不修改几何和材料语义，不改冻结研究合约，不建立后台几何服务，不推送/合并/发布。

## 当前验证

22 项针对性 Python/Node 测试通过。浏览器自动检查五类真实包的三种视图、选择、显隐保持、示例入口、六栏不裁剪，以及窄屏布局；主入口重新执行同样的检查通过。截图经代理查看，用户人工视觉验收仍单独待确认。

证据在 `evidence/GEOMETRY-WORKBENCH-01/unified-001/`。该 UI 任务没有重新运行科学实验；源包的实验 PASS 不提升为本次实验结果。Canvas 的透明度排序和穿透边界线仍只是显示手段，不是几何验证。
