# Final corrections: semantic types and gradient connectivity groups

This supersedes TAGS_CLARIFICATION.md's proposed tag model before that proposal was implemented. Goal ID and 09B task identity unchanged. Scope remains material library, explicit semantic configuration and standalone provenance; no geometry main-interface redesign.

Schema: dmslicer.workspace-annotation.v2. Each stable input record contains immutable geometry_role, semantic_type = Unassigned / Source / Gradient / Isolator, and material_id. Source requires a valid material on persistence (an incomplete draft can be edited). Gradient requires material_id=null; material control disabled. Changing to Gradient records the previous material in decision history before clearing.

Gradient uses gradient_group_id, default G, with user-created G1/G2 etc. These are connectivity group identifiers, neither materials nor decorative display names. Same group plus an explicit confirmed geometry relation allowing connection makes semantic connection eligible; different groups block semantic connection even if geometry reports contact. Unconfirmed/disallowed geometry never qualifies. The pure policy evaluator emits a machine-readable decision preserving the geometry fact separately. It does not merge domains, propagate/shared state, derive composition, or activate a field. Self-connections are rejected. Group equality alone proves nothing about geometry.

Isolator instance identity is (workspace source, owner_entity_ref); same display name on two objects does not merge identities. material_id may be null or an existing material. This preserves data while isolator_material_requirement=UNDECIDED is explicitly stored. It is not a future domain-engine decision that material is optional. No MaterialRegion/InterfaceSourceBoundary/field construction; no contact-based activation. The exported active relations list must be empty.

Library presets PLA / ABS / PETG / TPO contain category, name, UI display color and empty properties. Numeric user property values must carry unit, source and evidence reference. No gradient parameter fields in material forms.

Acceptance: Source missing material blocks save; Gradient clears assignment with trace, rejects direct-material imports and disables control; default G/custom G1/G2; same-group confirmed contact eligible, different-group contact blocked, unconfirmed relation blocked, self-connection rejected; Isolator same-name distinct owners and unresolved material policy; v1 imports rejected with explanation while retaining state; numeric property provenance enforced; four presets without numeric properties. Old v1 cache never silently migrates or overwrites. Frozen contract remains unmodified; ISOLATE ParticipationPolicy is not activated by UI annotations.
